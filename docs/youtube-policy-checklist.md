# AI 플레이리스트 채널 · 유튜브 규정 체크리스트

2026-11-25에 유튜브 공식 도움말 원문을 보고 정리했어요. 에이전트는 영상마다 아래 항목을 자동으로 검사하고, 하나라도 빠지면 텔레그램에 "업로드" 버튼을 띄우지 않아요.

## A. 업로드할 때 꼭 해야 하는 것 (에이전트가 자동으로 처리)

| # | 항목 | 이유 (공식 규정) |
|---|---|---|
| A1 | **"AI 사용(변경되거나 합성된 콘텐츠)" = 예** 로 설정 (API의 `containsSyntheticMedia: true`) | "AI generated music"은 반드시 밝혀야 하는 항목에 들어가요. 계속 숨기면 콘텐츠 삭제나 수익화(YPP) 정지까지 갈 수 있어요. 밝히는 것만으로는 노출이나 수익이 줄지 않아요. |
| A2 | 설명란 첫 부분에 안내 문구: *"All music in this video is original and was created with AI (ACE-Step), then selected and arranged by Window Seat Tapes."* | 시청자를 속이지 않기. 유튜브는 제목·썸네일·설명도 심사해요. |
| A3 | **아동용 아님** 으로 설정 | 아동용으로 잘못 설정하면 댓글이 꺼지고 광고 수익이 크게 줄어요. |
| A4 | 곡 목록 + 시간표(챕터) 를 설명란에 넣기 | 다른 영상과 내용이 실제로 다르다는 걸 보여줘요. |
| A5 | 제목·썸네일에 실제 가수 이름, 실존 인물 사진, 다른 채널 이름을 쓰지 않기 | 오해를 부르는 메타데이터와 사칭에 해당해요. |

## B. 수익화 거절을 피하는 것 ("진정성 없는 콘텐츠" 정책)

유튜브 원문: 영상마다 내용이 **"materially varied(실질적으로 달라야)"** 하고 가치를 줘야 해요. **"이미지 슬라이드쇼, 틀에 찍어낸 이야기"** 와 **"대량 생산처럼 보이는 AI 콘텐츠"** 는 수익화가 안 돼요. 대신 **"AI로 독창적인 배경 화면을 만드는 것"** 은 허용된다고 적혀 있어요.

| # | 우리 채널이 하는 일 |
|---|---|
| B1 | 회마다 **새로운 주제와 이야기**를 정해요 (예: 비 오는 성수동 저녁, 첫눈 오는 새벽 서촌). 곡 분위기, 장면, 제목, 설명을 모두 그 이야기에 맞춰요. |
| B2 | 회마다 **장면을 새로 그리고**, 비·눈·김·불빛 등이 **움직이게** 해요. 같은 그림을 다시 쓰지 않아요. |
| B3 | **곡은 전부 새로 만들어요.** 지난 영상의 곡을 다시 쓰거나, 다른 사람 곡을 섞지 않아요. 다른 가수 곡 모음은 허락을 받아도 수익화가 안 돼요. |
| B4 | **올리는 속도는 주 2회**예요. 하루에 여러 개를 쏟아내면 대량 생산으로 보여요. |
| B5 | **Jacob이 매번 직접 듣고 승인**해요 (텔레그램 딸깍). 사람이 고르고 다듬는 과정이 있다는 게 중요해요. |
| B6 | 채널 '정보' 란에 콘셉트를 솔직하게 적어요: AI로 만든 오리지널 음악, 사람이 큐레이션. 심사관이 이것도 봐요. |

## C. 하면 안 되는 것

| # | 금지 | 이유 |
|---|---|---|
| C1 | 내 영상에 봇으로 좋아요, 조회수, 댓글 달기 | "가짜 참여" 정책 위반이에요. 채널 정지 사유예요. |
| C2 | 작곡 프롬프트에 실제 가수 이름 넣기 (예: "in the style of ○○") | 저작권과 목소리 사칭 문제가 생겨요. 에이전트가 가수 이름이 들어간 프롬프트를 막아요. |
| C3 | 실제 사람처럼 보이는 AI 인물을 "진짜 가수"라고 소개하기 | 시청자를 속이는 콘텐츠에 해당해요. 그래서 우리 화면에는 사람이 나오지 않아요. |
| C4 | 다른 채널의 사진, 화면 구성, 채널 이름 따라 하기 | 재사용 콘텐츠이고 사칭에 해당해요. |

## D. 기록 남기기 (문제가 생겼을 때 이의제기용)

- 곡마다 **만든 날짜, 프롬프트, 모델 이름(ACE-Step 1.5), 라이선스(MIT, 상업 이용 가능)** 를 기록 파일로 저장해요.
- 저작권 신고(Content ID)가 들어오면 이 기록으로 이의제기해요. AI 음악은 남의 곡과 우연히 비슷하게 나올 수 있어서, 에이전트가 업로드 전에 무료 음악 인식으로 한 번 더 걸러요. *(무료로 쓸 수 있는지는 만들면서 확인할게요)*

## E. 수익화 자격 (참고)

- 기본 조건은 구독자 1,000명과 최근 12개월 공개 시청 4,000시간이에요. 1시간짜리 영상은 시청 시간을 쌓기에 유리해요.
- 거절되면 보통 약 90일 뒤에 다시 신청할 수 있어요 *(외부 기사 기준, 공식 페이지에서는 확인 못 함)*.
