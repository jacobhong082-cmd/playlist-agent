# Privacy Policy — playlist-agent

_Last updated: 2026-11-25_

playlist-agent is a personal automation tool run by the channel owner. It uploads the owner's own music playlist videos to the owner's own YouTube channel.

- **Data accessed:** only the owner's YouTube channel, through the YouTube Data API (`youtube.upload`, `youtube.force-ssl`), to upload videos and manage the owner's own video details and comments.
- **Data stored:** an OAuth refresh token kept as an encrypted GitHub Actions secret. No personal data of other users is collected, sold or shared.
- **Third parties:** none, other than Google/YouTube APIs as required to upload.
- **Revoking access:** the owner can revoke access at any time at https://myaccount.google.com/permissions.
- **Contact:** open an issue at https://github.com/jacobhong082-cmd/playlist-agent/issues.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
